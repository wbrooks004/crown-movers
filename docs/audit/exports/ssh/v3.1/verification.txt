NOTE on family=Anton: this marker persists. Root cause identified: it is loaded via
Bricks' own native Google Fonts enqueue (<link id='bricks-google-fonts-css'
href='https://fonts.googleapis.com/css2?family=Anton:wght@400&display=swap'>), a
Bricks typography setting, not any WPCodeBox snippet. No snippet in this unit's
scope controls it, and changing Bricks font settings is out of scope for this unit.
Per the unit's own instruction ("If a tracking or Anton marker persists, report
which... Do not try other methods"), this is reported and left untouched.

DEVIATION -- class-deletion scope (resolved by explicit user decision before any write):
The unit assumed only "crown-footer" was a live-referenced non-ACSS class (implying
209 deletions, 106 kept). Actual pre-state showed 95 of 210 non-ACSS classes were
referenced in live page/header content, including 4 of the 9 named "v6-collision"
classes (eyebrow, process, section-header, section-header--center). User selected
"Option C" (targeted): force-delete the 9 named collision classes regardless of
reference, keep the other 91 referenced-but-unnamed classes, delete the 115 truly
unreferenced classes. Net: 119 deleted, 198 kept (107 acss + 91 non-acss), all 9
named collisions confirmed deleted. See class-delete-list.csv for the full list and
per-class reason.
