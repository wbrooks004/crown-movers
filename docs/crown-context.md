# Crown Movers — Project Context

## Purpose

This file defines the permanent business, project, platform, and strategic context for the Crown Movers website.

Use it whenever working on strategy, information architecture, design, development, content, conversion, multilingual architecture, or future SEO.

---

## Business

Company: Crown Movers

Website:
https://www.crownmovers.ca

Current primary market:
Montreal, Quebec, Canada

Planned expansion:
Toronto, Ontario, Canada

Crown Movers is a moving company serving residential and related moving customers.

Do not invent business facts that have not been confirmed.

When additional factual information is needed, use confirmed project material, the existing Crown Movers website, or ask when the missing information materially affects the work.

---

## Core Positioning

Crown Movers should feel:

* Professional
* Established
* Trustworthy
* Friendly
* Approachable
* Organized
* Customer-focused
* High-quality
* Polished
* Accessible

The company should appear high-end in the quality of its presentation and customer experience without appearing expensive or exclusive.

The intended perception is:

**Excellent professional service at an accessible price.**

Avoid positioning Crown Movers as:

* A discount mover
* A bargain-basement company
* An exclusive luxury mover
* An impersonal corporation
* A generic local contractor

The website should make customers feel:

**“These people are professional, organized, trustworthy, and will take care of my move.”**

It should not create the impression:

**“This company is probably too expensive for me.”**

## Project Objective

The immediate objective is to rebuild the Crown Movers website.

The existing website is built with Oxygen.

The replacement website will use WordPress and Bricks Builder.

The rebuild should substantially improve:

* Visual quality
* UX
* Conversion
* Site architecture
* Maintainability
* Responsive design
* Accessibility
* Content presentation
* Technical architecture
* SEO scalability
* Multilingual scalability

The site should look like it was planned and built by a strong professional design and development team.

Do not accept “good enough for a local business” as the quality standard.

## Primary Conversion Goal

The primary website conversion is:

**Form submission**

The site should primarily guide qualified visitors toward requesting a moving quote.

Phone calls and other contact methods can remain useful secondary conversions.

Do not allow secondary actions to unnecessarily compete with the primary form conversion.

## Geographic Architecture

Montreal is the current primary operating market.

Toronto is a planned expansion market.

Architect the site now so Toronto can be added cleanly later.

Consider future geography when designing:

* URL structure
* Navigation
* Page hierarchy
* Service architecture
* Location architecture
* ACF structures
* Templates
* Components
* Forms
* Schema
* Internal links
* Multilingual relationships

Do not prematurely publish weak or misleading Toronto SEO pages before the company is ready to serve that market.

## Languages

The website will operate in:

* English
* French

Multilingual management will use Polylang Pro.

Both languages should be treated as first-class versions of the website.

French should not be treated as an afterthought or mechanical word-for-word translation.

For Quebec-facing French content, prioritize natural, appropriate Canadian/Quebec French while preserving the same business meaning.

Maintain equivalent conversion opportunities in both languages.
