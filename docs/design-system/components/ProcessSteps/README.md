# ProcessSteps
Three or four numbered steps as an ordered list on paper.

- Markup is `ol.process > li.process-step`; the big number is decorative (`aria-hidden`) because the list already numbers the steps.
- Numbers are coral numerals at `--h1` size (large text: 3.39:1 on paper, meets 3:1).
- Each step: an `h3` title at `--h4` size and one sentence.
