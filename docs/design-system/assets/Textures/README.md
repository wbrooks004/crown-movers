# Textures
Four original texture files authored for this project; their colours are baked in, so regenerate them if the palette changes.

| File | What | Colour | Tile / fit |
|---|---|---|---|
| `grain-on-light.svg` | fractal noise | ink #161513 at 11% alpha | 240px repeat |
| `grain-on-dark.svg` | fractal noise | white at 7% alpha | 240px repeat |
| `route-lines.svg` | dashed journeys with waypoints | coral #F04836, strokes 34%, dots 55% | 800x400, cover, right-anchored |
| `island-contours.svg` | contour rings of an island shape | ink #161513 at 12% | 800x600, cover |

On the site: upload to the media library under `crown-textures/` and assign them in ACSS Surfaces 1-5 (see Surfaces). Under 30 KB combined.
